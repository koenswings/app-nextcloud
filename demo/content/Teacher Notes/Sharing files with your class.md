# Sharing files with your class

These steps work for any teacher account in this Nextcloud.

## Share a folder with the class

1. Open **Files**.
2. Click the share icon next to a folder.
3. Type **Grade 5A** and choose the group.
4. Choose **View only**, so learners can open the files but not change them.

## Give learners a new worksheet

Put the file in the **Grade 5A** folder. Every learner in the class sees it
straight away.

## Collect work from learners

Ask each learner to share their file from **My work** with you. It then
appears in your **Shared with you** list.

## Office documents

Text, spreadsheet and presentation files open in the browser with Office.
Learners do not need to install anything.
