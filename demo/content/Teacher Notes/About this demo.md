# About this demo

This is the **Nextcloud Demo**: a practice Nextcloud for trying out IDEA with a
pretend class, Grade 5A. Nothing here is real school data. You can change or
delete anything.

## Demo accounts

Every password follows the IDEA rule: the account name followed by `911!`.

| Account  | Password       | Role                             |
|----------|----------------|----------------------------------|
| admin    | admin911!      | Administrator                    |
| teacher1 | teacher1911!   | Teacher, owns the class folder   |
| teacher2 | teacher2911!   | Teacher                          |
| learner1 | learner1911!   | Learner in Grade 5A              |
| learner2 | learner2911!   | Learner in Grade 5A              |
| learner3 | learner3911!   | Learner in Grade 5A              |

Change these passwords before you use Nextcloud with a real class.

## Groups

- **teachers**: teacher1 and teacher2.
- **learners**: all learners.
- **Grade 5A**: the class group (learner1, learner2 and learner3).

## Folders

- **Grade 5A** (owned by teacher1): the class folder. Learners in Grade 5A
  can open it but not change it. Teachers can change it.
- **Teacher Notes** (owned by teacher1): shared with all teachers.
- **My work** (in each learner's own files): a private space for that learner.

## Setting the demo up again

When the demo is set up again from the Console, missing accounts, groups,
files and shares are added back. Files that were changed are put back to the
demo version. Extra files you added are left alone. Passwords that were
changed are kept; the demo files of those accounts are then left as they are.
