Nextcloud packaging notes
- The demo hook (demo/hook.sh) uploads these files into the Nextcloud Demo:
  Class/ and Worksheets/ go to teacher1's "Grade 5A" folder (Worksheets/ as a
  subfolder), shared with the Grade 5A class group; Teacher Notes/ goes to
  teacher1's "Teacher Notes" folder, shared with the teachers group; Learner
  Files/ goes to each learner's "My work" folder.
- Third-party files are included unchanged. The African Storybook PDF is renamed
  only (the original file name has brackets, which pack paths do not allow);
  its content is byte-for-byte the publisher's file.
